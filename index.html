How to connect your free MongoDB Atlas cluster
1
Sign in to MongoDB Atlas and create or select your Cluster.
2
In Security → Database Access, create a database user with a password.
3
In Security → Network Access, add IP Address 0.0.0.0/0 (Allow Access from Anywhere).
4
Click Connect → Drivers (Node.js) → copy the connection string and paste it below.
Replace <username> and <password> with your actual database credentials.
Collections (students, attendance, accounts, rules) will sync here automatically.
